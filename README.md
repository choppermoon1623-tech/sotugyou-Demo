# 第80回 卒業証書授与式 ダッシュボード

登別市立登別中学校「第80回 卒業証書授与式」（令和9年3月11日〈木〉 10:00〜11:10）のためのダッシュボード型の単一ページアプリです。式次第や当日の進行を、1画面でまとめて表示・演出します。

🔗 **公開ページ:** https://choppermoon1623-tech.github.io/sotugyou-Demo/

## 使い方

- 公開ページ、またはリポジトリの `index.html` をブラウザで開くだけで利用できます。
- アセットを内蔵したバンドル済みページのため、オフラインでもそのまま表示できます。

## 構成

- `index.html` — アセット内蔵のバンドル済み単一ファイル（サーバー不要）

> ℹ️ デモ用の内容を含みます。実際の式で使う場合は日付・名称・進行を確認・調整してください。
